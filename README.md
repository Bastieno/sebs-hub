# Seb's Hub - Coworking Space Website

A modern, responsive website for Seb's Hub, a flexible solar-powered coworking space built for creators, professionals, and remote teams.

## Project Overview

This is a [Next.js](https://nextjs.org) project built with TypeScript and Tailwind CSS, featuring:

- **Modern Design**: Clean, professional interface with gradient accents
- **Responsive Layout**: Optimized for desktop, tablet, and mobile devices
- **Solar-Powered Theme**: Reflecting the eco-friendly nature of the coworking space
- **Interactive Components**: Hero section, services showcase, pricing plans, testimonials, and contact forms

## Features

- **Hero Section**: Compelling introduction with call-to-action
- **Services Overview**: Flexible workstations, meeting rooms, creator spaces, and more
- **Pricing Plans**: Transparent pricing for different membership tiers
- **Testimonials**: Customer feedback and reviews
- **Contact Form**: Easy booking and inquiry system
- **Social Integration**: Links to Instagram and Twitter that open in new tabs
- **Email Contact**: Direct email link (<sebastienohub@gmail.com>)

## Getting Started

First, install the dependencies:

```bash
npm install
# or
yarn install
# or
pnpm install
```

Then, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
